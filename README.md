## About the Project

EduTrauma Tools brings several browser-based clinical decision support applications for trauma care together in one web hub. The collection includes a dedicated open abdomen decision tool and AAST organ injury scales.

Users can work in Spanish, English, or Portuguese. The project also supports progressive web app use on compatible devices. Anonymous analytics and an integrated feedback mechanism provide information that can support future improvements.
